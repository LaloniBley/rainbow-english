# Rainbow English

Приложение для занятий английским по УМК Rainbow English 2 (Афанасьева, Михеева). Работает в браузере, ставится на компьютер как приложение (PWA) и не требует сервера. Курс приходит модулями: модуль = 7 степов + контрольная к ним.

## Запуск у себя

```bash
npm install
npm run dev        # http://localhost:5173
```

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и запушь в него эту папку (ветка `main`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша workflow `.github/workflows/pages.yml` соберёт и опубликует сайт. Адрес будет вида `https://<логин>.github.io/<репозиторий>/`.
4. Отправь Марине ссылку. В Chrome/Edge справа в адресной строке появится значок «Установить приложение» — после установки оно открывается как отдельная программа и работает без интернета.

Модули и материалы издателя в репозиторий не попадают (`modules/` и `*.zip` в `.gitignore`). Их ты передаёшь ей файлом.

## Отчёты на почту

В `public/config.json` лежит ключ Web3Forms. После каждого степа, контрольной и в конце модуля приложение отправляет письмо на почту, к которой привязан ключ. Бесплатно 250 писем в месяц. Без интернета письма копятся в очереди и уходят позже.

Ключ виден в публичном репозитории: им можно только отправлять письма на твою почту. Если начнётся спам — получи новый ключ на web3forms.com и замени его в `config.json`.

## Модули

Модуль — папка:

```text
module-02/
  module.json      упражнения, ключи, словарь, контрольная
  images/          картинки (jpg/png/webp)
  audio/           записи: sb-044.mp3 (учебник), wb-10.mp3 (тетрадь)
```

Проверить и упаковать в архив для Марины:

```bash
npm run pack-module -- путь/к/module-02
# → module-02.zip рядом с папкой
```

Скрипт проверяет, что id не повторяются, типы упражнений известны, ответы есть среди вариантов, а все картинки и записи на месте.

### Правка модуля

- Меняй `module.json`, увеличь `version` и упакуй заново. Марина добавляет новый архив так же, как первый — прогресс сохранится.
- **Не меняй `id` упражнений**, по ним хранятся её результаты. Новое упражнение — новый `id`.
- Подсказки полей в VS Code: добавь в начало `module.json` строку `"$schema": "../module.schema.json",` (путь до схемы из этого репозитория).
- Режим автора (Модули и настройки → Для автора курса) открывает все степы без блокировок и показывает id упражнений.

### Типы упражнений

| type | Что это | Ключевые поля |
| --- | --- | --- |
| `listen_repeat` | Послушай и повтори, прочитай вслух. Кнопка «Выполнено» | `audio`, `lines`, `ttsLines` |
| `info` | Правило или памятка | `text` |
| `choose` | Выбор одного или нескольких вариантов | `items[{id, prompt, options, answer, multi}]`, `free` |
| `match` | Соединить пары, справа могут быть картинки | `pairs[{id, left, right, rightImg}]` |
| `gap` | Вписать пропуски | `items[{id, prompt, text}]`, `caseSensitive`, `inline` |
| `copy` | Пропись: повторить образец N раз | `lines[{id, sample}]`, `times` |
| `order` | Расставить номера | `items[{id, label, fixed}]`, `answer` |
| `sort` | Разложить по группам | `buckets`, `words[{id, text, bucket}]` |
| `word_set` | Найти N слов (можно с сеткой букв) | `count`, `accept`, `grid` |
| `free` | Свободный ответ, идёт тебе на проверку | `items[{id, prompt, options}]` |

Пропуски в `gap`: `"Nel{l}"`, несколько верных ответов через `|` — `"{Lizzy|Lizzie}"`, свободный ответ по шаблону — `"{re:^(i'?m|my name is) [a-z]+$}"` (регулярное выражение, без фигурных скобок внутри; сравнение без учёта регистра и конечной точки).

Общие поля любого упражнения: `id`, `type`, `instruction`, `skill`, `source {book, page, ex}`, `img`, `images`, `audio`, `checkAudio` (запись «Проверь себя» — показывается после ответа), `note`, `teacher: true` (ключа нет, ответ уходит тебе «на проверку»). `answerKey: ["…"]` — образец ответа для кнопки «Показать ответ» в заданиях без автопроверки (в остальных ответы берутся из ключа сами).

### Словарь и диктант

У каждого степа есть `vocab`. Перед следующим степом по этим словам идёт диктант (на слух, по картинке или по переводу). `dictationMode: "choose"` — вместо письма выбор из вариантов (для самого начала). Перед Summing Up — большой диктант по словам всего модуля. Для перехода нужно 80%. При меньшем результате — повтор ошибок и пересдача.

### Контрольная

`tests[]` с `kind: "block"` открывается после Summing Up. 45 минут, вариант случайный, таймер локальный. Оценка: от 90% — 5, от 75% — 4, от 50% — 3 (меняется в `grading`). Следующий модуль открывается при оценке 3 и выше. Пересдача — не раньше чем через сутки, другим вариантом.
